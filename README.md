# 🚀 POCO X6 Pro 5G – Landing Page Promocional

Landing page desenvolvida para destacar os recursos e diferenciais do **POCO X6 Pro 5G**, com foco em performance, qualidade de tela, câmeras e usabilidade. O projeto apresenta uma experiência visual rica e imersiva, com ênfase na performance do dispositivo.

## 🎯 Funcionalidades

- 🌟 Destaques visuais do produto com imagens em alta definição
- 🎞️ Vídeos incorporados para mostrar funcionalidades
- 🎮 Ênfase em desempenho para jogos com WildBoost 2.0
- 🔋 Apresentação de bateria de longa duração com carregamento turbo
- 📷 Recursos fotográficos como OIS, EIS e filtros cinematográficos
- 🎨 Slider interativo com opções de cores
- 📱 Totalmente responsivo para mobile e desktop

## 💻 Tecnologias Utilizadas

- HTML5
- CSS3 (customizado + Bootstrap)
